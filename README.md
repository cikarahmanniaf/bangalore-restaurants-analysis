# Bangalore Restaurants Analysis

## Deskripsi

Repository ini berisi project **Data Mining & Visualization** mengenai analisis data restoran di Bangalore menggunakan **Zomato Bangalore Restaurant Dataset** yang diperoleh dari Kaggle. Analisis dilakukan untuk memperoleh wawasan mengenai karakteristik restoran, hubungan antara lokasi dengan jenis makanan, popularitas restoran, serta pola restoran berdasarkan wilayah di Bangalore.

## Dataset

Dataset yang digunakan adalah **Zomato Bangalore Restaurant Dataset**.

Beberapa variabel yang digunakan dalam analisis antara lain:

| Variabel          | Deskripsi                             |
| ----------------- | ------------------------------------- |
| `url`             | URL website restoran                  |
| `address`         | Alamat restoran                       |
| `name`            | Nama restoran                         |
| `online_orders`   | Ketersediaan layanan pemesanan online |
| `book_table`      | Ketersediaan layanan reservasi meja   |
| `rate`            | Rating restoran                       |
| `votes`           | Jumlah vote yang diterima             |
| `phone`           | Nomor telepon restoran                |
| `location`        | Lokasi atau neighborhood restoran     |
| `rest_type`       | Jenis restoran                        |
| `dish_liked`      | Hidangan yang populer                 |
| `cuisines`        | Jenis masakan yang tersedia           |
| `approx_cost`     | Perkiraan biaya untuk dua orang       |
| `review_list`     | Review yang diberikan oleh pengguna   |
| `menu_item`       | Menu restoran                         |
| `listed_in(type)` | Jenis layanan restoran                |
| `listed_in(city)` | Kota restoran                         |

## Research Questions

Analisis dilakukan untuk menjawab beberapa pertanyaan penelitian berikut:

1. Does the demography of an area matters?
2. Does location of a particular type of restaurant also depends on the people living in that area?
3. Does the theme of the restaurant matters?
4. Is a food chain category restaurant likely to have more customers than its counterpart?
5. Are any neighborhoods similar based on the type of food?
6. Is a particular neighborhood famous for its own kind of food?
7. If two neighborhoods are similar, does that mean these are related or particular groups of people live in the neighborhood?
8. What kind of food is more popular in a locality?
9. Do the entire locality love vegetarian food?
